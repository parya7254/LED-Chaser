# LED-Chaser
LED chaser for learning about analog sensors and killing my boredom. It will feature analog sensors and 555 timers, 10 LEDs, a potentiometer to control the speed, and a debug port!

# Why I Made This:

The reason for making this is that I really like designing PCBs for fun and also want to learn about analog sensors. I learned about 555 timers and how I could use them and also about the CD4017 IO expander. This project both gave me something to make and taught me about analog sensors.
